SortLab – How to make the two graphs in Excel
==============================================

1. Open SortLab_Graph_Data.csv in Excel (double-click the file, or in Excel: File > Open and choose the CSV).

2. Save as .xlsx (optional): File > Save As > choose "Excel Workbook (.xlsx)" so you can add charts and save everything together.

3. Graph 1 (Already sorted – ascending):
   - Select the first block: from "Size" (cell A2) through the last number in the Quick column (E7). Include the header row (row 2).
   - Insert > Charts > Line chart (e.g. "Line with Markers").
   - Put the chart on the same sheet or a new sheet. Title it: "Performance when elements are already sorted (ascending)".
   - X-axis = Size (1K, 5K, 10K, 15K, 20K). Y-axis = Steps. You should see 4 lines (Insertion, Selection, Merge, Quick).

4. Graph 2 (Sorted in descending order):
   - Select the second block: from "Size" (cell A10) through the last number in the Quick column (E15). Include the header row (row 10).
   - Insert > Charts > Line chart.
   - Title it: "Performance when elements are sorted in descending order".

5. Copy both charts into your report (Word/Google Docs) before exporting to PDF.
